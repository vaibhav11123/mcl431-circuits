# ADR-001 Untrusted model

Status: accepted

## Context

A language model can propose a YAML circuit. If it also writes SVG geometry, a pretty wrong sheet looks like an answer.

## Alternatives

1. Let the model emit SVG.
2. Let the model emit YAML and treat `draw` as always succeeding.
3. Treat the model as a frontend: YAML in, compiler decides whether a sheet exists.

## Decision

The model is untrusted. It does not write geometry and does not override eval. `draw_yaml` and CLI `draw` are fail-closed.

## Tradeoffs

Students cannot “just get a picture” for an illegal spec. Debug overlays exist for that.

## Revisit when

A proof assistant is in the tree, or a second authorised compiler backend exists.
