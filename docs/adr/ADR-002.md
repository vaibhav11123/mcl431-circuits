# ADR-002 YAML IR

Status: accepted

## Context

Sheets need a stable input that is not pixels and not FluidSIM.

## Alternatives

1. Coordinates in YAML.
2. Direct SVG edits as source.
3. `CircuitSpec` as the only IR: identifiers, sequence, valve types, L8 paths.

## Decision

`CircuitSpec` is the IR. No coordinates in YAML. Layout is a later pass.

## Tradeoffs

Authors cannot nudge a glyph by a millimetre in the spec. That is layout’s job.

## Revisit when

A student-facing drag editor must round-trip without losing verification.
