# ADR-003 Fail-closed draw

Status: accepted

## Context

A green drawing that fails eval is how B1 shipped `2Y1` on `K_START`.

## Alternatives

1. CLI `draw` bypasses `draw_yaml`.
2. Watermark every sheet.
3. Fail-closed by default; `--unverified` is the only escape hatch and watermarks `UNVERIFIED`.

## Decision

CLI `draw` and the web/MCP APIs call `service.draw_yaml`. Eval or refine failure returns no sheet.

## Tradeoffs

Lab debugging needs `--unverified`. That path is loud on purpose.

## Revisit when

`--unverified` is used in a graded hand-in.
