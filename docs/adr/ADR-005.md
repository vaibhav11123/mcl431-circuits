# ADR-005 Independent translation validation

Status: accepted

## Context

Calling the synthesizer twice is not an oracle.

## Alternatives

1. Diff two `compile_paths` runs.
2. SMT / Z3.
3. `spec_trace` (source) vs `env_trace` (target: sensors from modeled actuators).

## Decision

Independent `spec_trace` vs `env_trace`. Not CompCert. Not SMT by default. `verify_spec` must not import `compile_paths`.

## Tradeoffs

Timers and cascade are `UNSUPPORTED`. Truncated mutex is `INCONCLUSIVE`, never silent `PASS`.

## Revisit when

3-cylinder mutex enumeration exceeds 2s (then consider symmetry or Z3 by a new Ruling).
