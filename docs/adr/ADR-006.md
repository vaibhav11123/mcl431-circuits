# ADR-006 Shared CLI and browser

Status: accepted

## Context

Chat, workspace, and CLI must not diverge on “is this legal?”

## Alternatives

1. Separate JS renderer.
2. Pyodide in the browser running the same `draw_yaml`.
3. Browser as a viewer; localhost CLI/HTTP for this VM.

## Decision

One Python compiler. Chat preview PNG ≤800px / 200KB. Full YAML + `get_sheet` for print. Browser Generate uses in-browser `draw_yaml` when Pyodide loads; otherwise localhost `/api/draw`.

## Tradeoffs

Pyodide download is large. GitHub Pages still works as a YAML editor plus CLI instructions if WASM fails.

## Revisit when

Pyodide cannot install pydantic-core, or a second language backend appears.
