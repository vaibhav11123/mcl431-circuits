# ADR-007 No physics, no host required

Status: accepted

## Context

Pressure gauges and FluidSIM look like verification. They are not this compiler.

## Alternatives

1. Bundle a CFD/fluid simulator.
2. Require Fly.io for every draw.
3. Logical 0/1 traces only. Workspace + CLI work with Fly down.

## Decision

Logical traces only. Pressure simulation is a refusal. `PHY001` is `not_evaluated`. Hosted Fly is optional.

## Tradeoffs

We will not certify a machine. Manifests must not store `not_evaluated` as `passed`.

## Revisit when

A faculty-owned lab asks for a separate physics product, not a silent add-on.
