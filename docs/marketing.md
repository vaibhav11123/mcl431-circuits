# Marketing copy (what to say, what not to say)

Do **not** call this an AI circuit generator. The compiler is the product.

## One line

Verification-oriented compiler for AI-generated engineering systems.

## Two lines

A language model may propose a YAML circuit. A deterministic compiler decides whether that spec is allowed to become a sheet.

## Student sentence

From engineering problem to verified circuit. Draw it, understand it, modify it, explain it.

## Staff sentence

How do you let a probabilistic model propose an engineering artifact without giving it authority over correctness?

## GitHub about / subtitle

`Verification-oriented compiler for AI-generated engineering systems.`

Never write “formally verified compiler.” Bounded translation validation is not CompCert.

## Launch post (paste)

Sequence Circuit is a compiler, not a chatbot skin.

You type (or a model types) a pneumatic/hydraulic sequence as YAML. The compiler either emits ISO/L8 sheets or it refuses — with an English sentence, not a pretty wrong drawing.

- Independent source vs target traces (`spec_trace` ⋈ `env_trace`)
- Discrete TIMER ticks, deadlock FAIL, cascade electrical check
- Pressure physics: refused. FluidSIM `.ct`: refused.
- SequenceBench-300: 220 legal / 80 illegal, error rates 0 and 1 on this release VM
- Runs locally. No Fly. No API bill. Browser workspace is static Pyodide.

Repo: https://github.com/vaibhav11123/mcl431-circuits

## What not to claim

- Hosted on Fly
- Listed in the ChatGPT or Claude directories (not submitted)
- Physical safety certificate
- Wall-clock TIMER / pressure drop / cascade fluid physics
- Live LLM benchmark scores (fixtures only)
- Student-study results (protocol only)
