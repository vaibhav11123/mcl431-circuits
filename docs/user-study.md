# User study protocol (template only)

This is a faculty/TA protocol. Do not invent results.

## Goal

Measure whether students can go from a stated sequence to a verified sheet, then explain a fail-closed rejection, without treating the model as an authority.

## Participants

15–30 MCL 431 students. Consent. No grade impact. Course pack stays off the public ISO workspace.

## Tasks (per person, ~45 minutes)

1. Load the ISO two-cylinder example. Generate. Name the solenoids on the electrical sheet.
2. Change the sequence. Generate. Say whether the compiler accepted and why.
3. Paste an invented valve id. Read the rejection sentence.
4. Ask for a pressure simulation. Confirm the explorer is offered, not gauges.
5. Optional: `--unverified` only if a TA is present; record that the watermark is noticed.

## Data to collect (no fake numbers)

- Task completion (yes/no)
- Time to first accepted sheet
- Whether the student trusted a rejected debug overlay as a “solution”
- Free-text: “who decides if the circuit is correct?”

Descriptive only. Do not claim learning gains without the collected table.
