L14 Fan Controller — exam-ready structure
I/O: PB I0.0; AI Slot-2 T/RH; AO Slot-1 10-bit; L1–L3 Q0.0–2

Four sections
  1–3   Start/stop toggle
  4–6   Which T/RH zone is active
  7–10  Set fan speed (AO)
  11–13 Matching indicator lamps
  14    Store RUN → M0.5 for *next* scan

Toggle (previous-state safe)
  1  PB · ONS → M0.1 pulse   (one shared edge)
  2  pulse · !M0.5 → (L) RUN  (prev was OFF → start)
  3  pulse ·  M0.5 → (U) RUN  (prev was ON  → stop)
  14 RUN → M0.5               (write prev_RUN last; used next scan)

M0.5 is last scan’s RUN. Do not copy RUN at the top of the program before
OTL/OTU — that can blur “previous” vs “just latched” in the same scan.

Zones / AO / lamps
  Z1 M0.2: 30<T<40 & RH>50  → MOV 205 + L1
  Z2 M0.3: 40<T<50 & 40<RH<50 → MOV 512 + L2
  Z3 M0.4: T>50 & RH<40     → MOV 818 + L3
  Then !Z1·!Z2·!Z3 → MOV 0 (does not run when a zone MOV just wrote)

Memorise: Toggle → zone → speed → lamp. Same zone bit for AO and lamp.
