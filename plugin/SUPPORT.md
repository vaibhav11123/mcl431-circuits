# Support

- GitHub issues on the Sequence Circuit repository.
- Local CLI: `python -m circuit draw <spec.yaml>`
- Local MCP: `python -m circuit.mcp_server` (stdio) or `--http --host 127.0.0.1`
- Browser workspace: serve `web/` as static files. Pyodide runs the compiler in the browser. No Fly account.
